# Poweroff Notify Daemon - Changelog

## [1.0.0] - 2026-10-08

### Добавлено
- Первоначальная версия проекта
- GUI-демон с системным треем (AppIndicator3)
- Обратный отсчёт времени до выключения (обновление раз в минуту)
- Интерактивные уведомления с кнопками "Продлить" / "ОК"
- Конфигурация через INI-файл с поддержкой пользовательских секций
- Регистронезависимое определение имени пользователя
- **Поддержка `shutdown_time = none`** для отключения выключения конкретных пользователей
- XDG autostart для автоматического запуска при логине (все DE)
- Systemd timer для резервного выключения (независимо от демона)
- Утилита sync-timer.py для синхронизации времени из конфига
- Пользовательские иконки проекта (SVG + PNG в разных размерах)
- Скрипты установки и удаления (install.sh, uninstall.sh)
- Спецификация RPM-пакета для ALT Linux (poweroff-notify-daemon.spec)
- Полная документация (README.md, OVERVIEW.md, MIGRATION_NOTE.md)

### Особенности
- Совместимость с GNOME 48+, KDE, MATE (через AyatanaAppIndicator3)
- Поддержка X11 и Wayland
- Двухуровневая защита: XDG autostart + System timer
- Централизованное управление через GPO/Samba AD
- Выключение через polkit + systemd-logind
- Гибкая настройка per-user: отключение выключения, изменение времени, параметров
